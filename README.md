# Hestia

Sistema de reserva de hotel desenvolvido como projeto acadêmico nas disciplinas de Engenharia de Software III e Laboratório de Engenharia de Software — Fatec Mogi das Cruzes.

## Sobre o projeto

O Hestia cobre o ciclo completo de uma reserva de hotel — do cadastro do hóspede ao check-out — incluindo gestão de quartos, pagamentos, promoções, políticas de cancelamento e notificações.
